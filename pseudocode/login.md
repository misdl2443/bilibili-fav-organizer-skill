# login（阶段零：登录）

> 伪代码（不可执行），仅示意流程。

## 职责
从干净浏览器走到"已登录且知道账号标识（mid）"的状态，首次必须，之后沿用登录态文件。

## 流程（两段式）
1. **open 模式**：
   - 读取当前登录态（账号信息接口 + cookie 账号 ID 兜底）
   - 若已登录 → 记录 mid，输出"已登录"，跳过扫码
   - 否则 → 打开登录页，输出"需要登录"，**agent 截图展示二维码给用户扫码**
2. **wait 模式**：
   - 轮询登录态（默认最多 120 秒，每 3 秒查一次）
   - 成功 → 写 `login.json`（含 mid、昵称、时间戳），输出"登录成功"
   - 超时 → 输出"等待扫码超时"，用户扫完码后重跑本模式

## 关键点
- 登录走干净浏览器扫码，不碰用户现有浏览器，不提取其 cookie。
- mid 来源：账号信息接口返回；cookie 账号 ID 兜底。
- 登录后跳转收藏夹页面（GUI 流程起点）。

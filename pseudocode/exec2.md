# exec2（阶段三：批量执行器）

> 伪代码（不可执行），仅示意流程。

## 职责
按分类结果，把视频**批量移动**到目标收藏夹、对失效视频**批量取消收藏**。

## 流程
1. 读 `folders.json`（类目→收藏夹映射）+ `classified.json`（分类结果）+ 残留清单（真实剩余）
2. 构建队列：
   - 失效视频（失效标记非 0）→ 入"取消收藏"队列
   - 活视频且有分类且目标夹存在 → 入"移动"队列
   - 无分类/无目标夹 → 入"未知"清单（跳过，最后报告）
3. **移动**：按（源夹, 目标夹）分组，每组 ≤10 条，批量参数**逗号分隔单个参数**；类型后缀取记录 type 字段（从残留清单或盘点数据反查，兜底普通稿件类型）
4. **取消收藏**：按源夹分组，≤10 条/批，同上
5. 批量失败 → 逐条单发兜底；风控码冷却退避重试
6. **断点续传**：每批把成功项追加进执行日志；**强制补跑模式**（忽略历史成功记录）用于抽干发现残留后的重试
7. **限速**：每请求间隔 1.1~1.6 秒 + 每 40 请求暂停 3 秒

## 关键点（三条铁律）
- 批量参数绝不重复参数名（服务端只认第一个且返回成功码）。
- 类型后缀必须取记录字段，写错静默无效。
- **成功码 ≠ 生效**：执行完必须抽干复核源夹，残留重新入队补跑，循环到抽干为 0。

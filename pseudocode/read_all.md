# read_all（阶段一：盘点读取）

> 伪代码（不可执行），仅示意流程。

## 职责
把指定收藏夹的视频**全部读取**出来，落盘成 `fav_all.jsonl`（每行一条视频记录）。

## 流程（双通道读取）
1. **断点续传**：读输出文件里已有的收藏夹 id，已读的整夹跳过
2. 对每个待读收藏夹，循环分页（每页 N 条）：
   - **通道 A（优先）**：浏览器内同步请求（快）
   - **通道 B（兜底）**：连续失败 2 次（只读拦截/异常）→ 自动切换为"跳转接口地址 + 读取页面文本"（稳），本夹后续不再回头试 A
   - 解析返回：提取本页视频列表，逐条写 `fav_all.jsonl`（JSONL 追加）
   - 检查"是否有更多"标记：有则下一页，无则结束本夹
3. **限速**：每页间隔 1.1~1.8 秒（随机抖动）；风控码冷却重试（20 秒起递增）
4. 中断可重跑：已读夹跳过，只读未读完的

## 关键点
- 必须循环"是否有更多"，不能按"本页条数不足"停。
- 记录字段：收藏夹 id/名、aid、bvid、类型、标题、UP 主、失效标记、时长、收藏时间、封面、简介。
- 双通道是"失败自动切换"，编排方无需干预。

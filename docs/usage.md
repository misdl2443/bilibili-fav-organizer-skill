# 使用说明（完整总览）

把混乱的 B 站收藏夹整理成按用途分类的文件夹。读取全部收藏夹 → 按「标题+标签+封面」分类 → 批量移动到对应收藏夹 → 清理失效视频。

> **本发布版为方法论文档，不含任何可执行代码。** 所有步骤以文字描述或伪代码示意（见 `pseudocode/`），真实接口、请求形态、页面元素请按平台官方文档现场核对。使用前请阅读 `DISCLAIMER.md`。

## 快速开始

1. **触发**：对 agent 说「整理我的 B 站收藏夹」即可（技能自动触发，无需手动加载）。
2. **首次登录**：干净浏览器打开 B 站 → 截图二维码 → 用户扫码 → 记录账号标识到 `login.json`。不碰用户的现有浏览器。
3. **数据目录**：统一用一个目录（如 `<数据目录>`），所有中间文件都在其中，中断后重跑自动续传。

## 工作流程（四阶段）

| 阶段 | 做什么 | 产物 |
|---|---|---|
| 0 登录 | 干净浏览器扫码，拿到账号标识 | `login.json` |
| 1 盘点 | 读全部收藏夹 + 所有分页视频 | `folders_raw.json`、`fav_all.jsonl` |
| 2 分类 | 拉标签（可选）→ 主模型定类目 → 无图判断优先、封面视觉兜底；未分类二次筛选后归档 | `tags.jsonl`、`categories.json`、`classified.json` |
| 3 执行 | 生成执行计划（人工确认）→ 改名/建夹/删空夹 → 批量移动 + 失效取消 → 抽干验证循环到清空 | 执行计划、`folders.json`、执行日志、残留清单 |

## 特性

- **类目完全自适应**：不限于任何预置清单，按你的收藏夹名/标签聚类动态生成，每个账号的分类体系都贴合实际内容。
- **降级链完整**：本地视觉模型 → 无则文本子代理 → 子代理卡死则主模型直接分类。
- **标签优先**：明确标签直接分类（纯文本快）；标签缺失/泛标签才下载封面走视觉兜底。
- **防静默失败三铁律**：批量参数不重复名 / 类型后缀取记录字段 / 成功码必须抽干复核。
- **GUI 兜底**：接口被风控卡死时，页面点击逐条移动（含"位置刷新"方法论）。
- **断点续传**：每个中间文件都可断点，重跑跳过已完成项。
- **发现方法论**：`docs/discovery-methodology.md` 描述**通用黑盒观察法**（如何通过平台自身的页面交互观察网络活动、识别数据结构、最小验证），**不指向任何特定平台实现，不含工具名称/接口地址/操作步骤**——请结合目标平台协议自行判断合规性。
- **任务结束自动清理**：关浏览器、删临时文件、卸载模型、提示清浏览器站点数据。

## 环境要求

- 任意平台 + 已登录的目标平台账号（本发布版以 Bilibili 为例）。
- 分类阶段可选：本地视觉模型（封面兜底用）或任意文本大模型（子代理/主模型判断）。
- 全程限速防风控；轮次间冷却。

## 安全与隐私

- 封面/标签分类走本地视觉模型（若有），图片不出本机。
- cookie 仅存在于浏览器会话，只读单值、不落盘。
- 数据目录含账号关联信息，**不要放入 git 仓库 / 网盘自动同步**。
- 任务结束清理浏览器、临时文件与模型显存。

# gui_exec（阶段三：GUI 兜底）

> 伪代码（不可执行），仅示意流程。页面元素选择器以现场快照核对为准（见 docs/gui-flow.md）。

## 职责
接口写入被风控卡死时，在收藏夹页面**点击处理当前第一个视频**（移动至 / 取消收藏）。

## 流程
1. 页面必须在收藏夹页（视频网格视图）
2. 取当前**第一个**视频：
   - 无视频 → 输出"列表已空"，结束
   - 有视频 → 打开（点击）第一个的"更多选项"按钮，等下拉开
3. 分支：
   - **目标为"取消收藏"**（已失效视频）→ 点下拉菜单的"取消收藏"项
   - **目标为某收藏夹** → 点"移动至"项 → 等弹框 → 选中目标收藏夹（点外层标签，校验选中态）→ 点"确定"
4. 等待 1.5 秒，验证：首位视频已变化（被下一个顶替）或列表已空

## 关键点
- **位置刷新**：处理完第 1 个，第 2 个顶到第一位——一页多个视频时循环调用本流程，目标按第 N 个视频标题定，直到"列表已空"。
- 每步 1~2 秒等待：等 DOM 刷新，天然避风控。
- 单选框/按钮等页面元素以现场快照核对实际位置与标识，不写死。

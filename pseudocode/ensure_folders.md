# ensure_folders（阶段三：收藏夹规划执行）

> 伪代码（不可执行），仅示意流程。

## 职责
按执行计划创建缺失收藏夹、删除已确认空的收藏夹，输出"类目→收藏夹"映射 `folders.json`。

## 流程（plan 模式）
1. 读执行计划（reuse 映射 / create 清单 / delete 清单）
2. **先 create**：对每个缺失类目，调"新建收藏夹"接口（POST + CSRF 令牌），记返回的新收藏夹 id
3. **后 delete**：对每个待删收藏夹，调"删除收藏夹"接口（参数为复数形态，先核对平台当前文档），返回成功才从映射里剔除
4. 合并映射：reuse（直接映射）+ create（新建映射）→ 写 `folders.json`（含账号标识 + 类目→收藏夹映射）
5. 每个写操作后限速（1.1s+）；风控码退避重试

## 关键点
- **非空夹绝不列入 delete**（删除非空夹可能导致视频消失）。
- 执行顺序先建后删。
- 删除接口参数形态（复数）与单数不同，写错返回参数错误——以平台当前文档为准。
- 冒烟测试：先删一个已确认空的收藏夹验证写链路通，再批量。

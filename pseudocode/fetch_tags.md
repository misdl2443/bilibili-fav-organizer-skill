# fetch_tags（阶段二：拉取标签）

> 伪代码（不可执行），仅示意流程。

## 职责
按视频标识逐条调用平台标签接口（若平台提供），把每个视频的**标签**拉到 `tags.jsonl`——标签是分类的第一信号，明确标签直接定类，无需封面。

## 流程
1. 从 `fav_all.jsonl` 收集去重的视频标识（bvid）
2. **断点续传**：`tags.jsonl` 里已有的 bvid 跳过；带错误标记的行跳过（需删行才重拉）
3. 对每个待拉视频：
   - 调用标签接口（浏览器上下文或免登录直连均可，视平台）
   - 成功 → 提取标签数组，写 `tags.jsonl`（aid/bvid/标题/标签/时间）
   - 风控码 → 冷却退避（20 秒起递增）重试
4. **限速**：每请求间隔 1.1~1.6 秒
5. 上古视频可能 0 标签 → 标签为空数组（走封面视觉兜底）

## 关键点
- 分类用法：把标签拼进分类输入（`标题 | 标签：tag1,tag2`）作为语义输入。
- 有明确标签的条目不传封面图；标签缺失/泛标签才走封面视觉兜底。
